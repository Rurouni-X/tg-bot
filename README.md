# 🤖 Telegram Read Adviser Bot

Telegram-бот на Go для сохранения и случайной выдачи ссылок. Помогает хранить прочитанные материалы и быстро получать к ним доступ.

## ✨ Возможности

- Сохранение ссылок через Telegram
- Выдача случайной ссылки по запросу
- Минимальные зависимости — только стандартная библиотека Go

## 🚀 Быстрый старт

### 1. Получи токен бота

1. Открой [@BotFather](https://t.me/BotFather) в Telegram
2. Отправь команду `/newbot`
3. Следуй инструкциям и получи токен

### 2. Запуск

```bash
./tg-bot -token-bot 'YOUR_BOT_TOKEN'
```

## 📦 Установка

### Требования

- Go 1.21 или выше
- Telegram аккаунт

### Сборка

```bash
git clone <твой-репозиторий>
cd <твой-репозиторий>

go mod tidy
go build -o tg-bot .
```

## 📖 Использование

После запуска отправь боту в Telegram:

- **Ссылку** — чтобы сохранить
- **Команду** (например, `/random`) — чтобы получить случайную ссылку

## ⚙️ Параметры

| Параметр | Описание | Пример |
|----------|----------|--------|
| `-token-bot` | Токен от @BotFather | `123456789:ABCdef...` |

## 🏗️ Особенности

- Написан на чистом Go без внешних библиотек
- Использует только стандартную библиотеку
- Лёгкий и быстрый

## 🛠️ Разработка

```bash
# Запуск в режиме разработки
go run main.go -token-bot 'YOUR_TOKEN'

# Сборка
go build -o tg-bot .
```
